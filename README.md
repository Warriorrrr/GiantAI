# GiantAI
Gives giants the same entity goals as zombies.

## Downloads
You can get the plugin from [Modrinth](https://modrinth.com/plugin/giantai) or from [GitHub releases](https://github.com/Warriorrrr/GiantAI/releases).

## Installation
This plugin is very simple to install as it has no config or dependencies, simply add the plugin to your server, restart it, and you're good to go.
